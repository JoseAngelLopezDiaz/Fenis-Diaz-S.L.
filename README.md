# Fenis Díaz S.L.

Web corporativa privada para Fenis Díaz S.L., empresa de transportes y logística con sede en Córdoba.

## Desarrollo

```bash
pnpm install
pnpm dev
```

La web no incluye todavía datos reales de contacto ni está preparada para publicación pública. Antes del lanzamiento deben confirmarse teléfono, correo electrónico, cobertura, servicios específicos y dominio.
